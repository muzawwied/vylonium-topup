# Vylonium — Top Up Game Instan

Situs top up game multi-halaman, 100% vanilla (HTML/CSS/JS, tanpa dependency).
Deploy di GitHub Pages: https://muzawwied.github.io/vylonium-topup/

## Fitur
- 6 halaman: Beranda, Games, Top Up (alur 4 langkah), Status, Bantuan, Kontak + 404
- Tema terang/gelap (persist, default mengikuti sistem) — aksen blurple ala Discord
- Animasi: preloader, typing, scroll reveal, counter, marquee, tilt 3D, progress bar
- Alur top-up interaktif + riwayat pesanan (localStorage) + cek status real-time
- Mode produksi: SEO meta, OG, sitemap, robots, favicon, prefers-reduced-motion, responsif

Logo game diambil dari Wikimedia Commons / Wikipedia untuk keperluan identifikasi;
merek game adalah milik pemilik masing-masing.
